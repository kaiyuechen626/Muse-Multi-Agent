# Muse 手机与电脑局域网同步

此功能连接 Muse Cyrene Android 与 Muse Multi-Agent 电脑服务。首次配对可选择二维码或 USB；配对完成后使用局域网自动同步，不再依赖数据线。电脑服务需要保持运行，手机需要连接同一局域网。

## 首次配对

电脑打开 Muse 的设置 → 手机与电脑局域网同步。

- 扫码：点击“扫码配对”。手机打开设置 → 数据与备份 → 局域网同步，扫描电脑二维码，再确认显示的电脑地址。也可从照片识别二维码。二维码三分钟有效、只使用一次。
- USB：连接数据线，启用 Android USB 调试，并在手机系统提示中允许自己的电脑。电脑点击“USB 配对”，手机会打开配对页，点击“确认与此电脑配对”。系统授权需由用户操作。

首次同步按资料稳定 ID 区分身份。两端独立创建的角色同名时，电脑和手机都会显示“发现同名 AI”，可选择“合并”或“分别保留”，也可以稍后处理。选择前暂停这批资料同步，任一端作答即可继续；分别保留会记住选择，后续不反复询问。

选择合并后，统一角色身份，汇总聊天和事实记忆，相同文字及分类的记忆去重并保留较高重要度。以已有电脑角色设定为主，空字段从另一角色补充，不同设定保存冲突副本。电脑在本地 `lan-sync/identity-merges` 留存原始合并备份。如果手机本机已有两份对应角色，重复项保留为停用的“已合并备份”，聊天移到保留角色，原事实数据库也保留；本机只有一份时，继续使用其本机配置并映射到统一身份。密钥、模型服务配置及 DSH 权限继续留在本机。合并中断后会从日志恢复，重复同步不会重复创建资料。配对页始终由用户选择方式并确认。

## 同步内容

- 角色名称、提示设定、受支持头像和便携字段。
- 文字聊天、消息顺序、收藏、会话置顶和归档状态。
- 角色的事实记忆。

API 密钥、模型服务凭据、DSH 配对与插件授权、本地语音模型不传输。图片、视频、文件附件、工具运行明细及高级会话分支不作为跨端文件同步对象；已存在的手机消息保留自己的这些字段。无法在另一端表达的字段尽量保留在同步基线中，避免无修改地反复改写。

## 重连与冲突

手机运行时约每 20 秒检查；网络重新连接会触发检查。后台由 Android WorkManager 调度（至少约 15 分钟），省电限制或强制停止会延迟到系统允许或再次打开应用。生成回复期间等待，不将未完成回复同步。

电脑地址变化后，通过配对密钥认证的 UDP 响应发现电脑。离线新增消息可按 ID 合并；无法自动合并的同一字段修改保存双方副本，可在两端同步页导出核对。批量上传每次 16 条；未收到确认的后续批次修改继续保留。

电脑可暂停同步或撤销某个手机；手机可解除本机配对。撤销后重新连接需要重新配对，解除配对不删除角色、聊天或记忆。

## 网络与存储

电脑本地管理界面仍只监听 127.0.0.1:3210。开启同步后，另开 TCP 3212 和 UDP 32113，仅接收本机和私有网段应用请求。学校/访客 Wi-Fi 若隔离终端，会阻断局域网同步；USB 配对本身不能解除这种网络隔离。

配对使用 256 位随机一次性秘密，后续每台设备独立密钥。所有资料经 AES-256-GCM 认证加密，方向、设备与请求 ID 绑定。手机凭据通过 Android Keystore 加密写入原子状态文件；电脑状态在用户本地数据目录保存，应按电脑账号权限保护。不要分享未失效二维码或包含配对密钥的状态文件。

## 验证

电脑测试：`node --test test/lan-sync*.test.mjs`。手机测试类 `io.zer0.muse.sync.LanSyncDeviceTest` 包含加密认证、二维码解码、隔离 Room 数据回写及同名角色合并；可通过一次性隔离电脑服务验证真实 Android TCP 双向传输、合并确认和记忆去重。测试不写入用户正式角色与聊天。
