# 多 AI 聊天室

电脑左侧「本地聊天」分为「单独聊天」和「聊天室」两个独立列表，各有自己的创建入口，搜索和归档也按当前分类显示。进入「聊天室」点击「＋ 多 AI 聊天室」，选择 2–8 个现有角色并填写可选名称。勾选顺序就是默认发言顺序。

发送消息后，各角色依次回复，后发言者能看见前面的公开发言。顶部「本轮发言」可改为仅某个角色回复。每条回复显示对应角色名称、头像和时间；同名角色仍按各自身份 ID 区分。

## 人格与记忆

- 每次回复分别读取发言角色当前的人格、模型参数、长期记忆和历史检索结果。其他成员的人格设定和私人记忆快照不会传入该角色的模型请求。
- 聊天室的公开发言可被所有成员读取。角色主动说出的内容会成为共享聊天内容。
- 公开聊天原文归档到每位成员自己的记忆目录；成员只保留自己的私有记忆追踪。其他角色的单聊和长期记忆不共享。
- 完整回复后，自动记忆按该角色自己的开关单独提取、保存并关联来源。其他 AI 的发言不会当作用户陈述提取事实。自动记忆不是逐字保存；完整原文另行保存。
- 点击顶部成员可查看、编辑对应角色的记忆。右键 AI 回复可将内容存入该发言角色的记忆；用户消息可先选择「仅某个角色」再存入该角色的记忆。

## 中断、保存和导出

- 「停止生成」保留已完成回复和当前角色的部分文字。「继续未完成回复」只补完未完成成员，重新生成当前角色的部分文字，不重复已经完成的角色。
- 也可直接发送新消息开启下一轮。关闭、刷新页面或重启后，已保存的消息与待回复成员仍保留。
- 聊天室支持改名、搜索、收藏、置顶、归档、回收站、摘要及消息编辑分支。编辑用户消息后，分支内所有成员重新回复；原聊天室不变。聊天室暂不提供单条回复版本切换。
- JSON、Markdown 导出保留发言者。完整备份保留成员身份、私有记忆、发言者与待回复进度。单独导入聊天室 JSON 需要原成员已存在；换电脑建议使用完整备份恢复角色与聊天。

## 当前范围

电脑端是文字聊天室。成员在创建时选择；要使用另一组成员，可新建聊天室。聊天室暂不参与 QQ 接入或 DSH 工具调用。

手机 0.3.0-chatrooms.1 起，在独立的「群聊」页面创建和打开聊天室，单聊仍在原来的单聊页面。沿用手机各角色的人格、模型与记忆设置，回复展示发言者姓名；同名成员增加身份后缀。

## 手机与电脑同步

- 沿用已有局域网配对；两端更新后，自动同步 2–8 位角色的聊天室名称、成员、公开文字发言、发言者身份、置顶和归档。
- 手机悄悄话、图片/文件附件、共享文档、成员专属上下文、群聊专用摘要记忆和讨论模式保留在手机。角色长期记忆仍按原有独立角色同步。私信不会变成公开发言，电脑删除公开消息也不会删除手机私信。
- 电脑删除聊天室时，手机保留归档副本以保留仅手机有的内容；恢复或编辑该副本可重新同步。手机删除整个聊天室则向电脑发送删除记录。
- 电脑暂停轮次的元数据随聊天保存；手机开始新的公开发言后清除旧暂停计划。手机不自动执行电脑尚未完成的回复。
- 旧手机不会收到聊天室记录；手机升级后自动补发先前跳过的聊天室。新手机连接旧电脑时继续同步单聊，提示更新电脑后再同步聊天室。
- 旧手机群聊若包含团队代言、已退出的历史发言者或超出 2–8 位角色，暂只保留在手机，同步状态会提示。已有电脑副本不会因此被删除。
- 同一聊天室中的同名成员必须保留不同身份。两端同时修改同一字段时仍按原有同步机制保留冲突副本。

删除某成员后仍可查看历史，并指定剩余角色发言；全员回复需先从回收站恢复缺失成员。若同名身份的合并会把一个聊天室里的两位成员合成一位，应在同步提示中选择「分别保留」。

每个发言角色分别调用模型，开启自动记忆或摘要还会额外调用；回复人数越多，等待时间与 API 用量通常越多。
