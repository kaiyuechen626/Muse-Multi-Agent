# Alpha 功能边界

- 这是需要 Node.js 24 的本机网页应用源码版，不是独立 EXE，也不是公网多用户服务。默认只监听 127.0.0.1，不能直接部署为公开站点。
- 当前为单角色聊天；项目名称中的 Multi-Agent 不表示已支持群聊。手机实时记忆/聊天同步未实现。导入是快照，不是实时连接。
- 普通回复可流式显示和停止。授权工具的回复当前等待完整正文；停止不能撤销已产生的工具副作用。
- DSH 可选，需要兼容宿主及已打开且空闲的会话；当前本机验证基线 0.2.0-rc.2。审批由 DSH 执行，插件不会替用户自动同意。配对和授权重启失效。
- 真实 DSH 配对、角色授权和测试文件读取已通过；模拟模型结合真实 DSH 的工具往返已通过。真实 DeepSeek 工具往返尚未完成验收，不把模型模拟当作真实模型成功。
- 自动记忆、摘要和模型回复可能出错，并可能产生额外 API 费用。检索与质量检查包含文字规则，不保证语义准确。
- DPAPI 密钥仅支持 Windows 当前用户；跨电脑恢复需重新填写 Key。浏览器草稿和偏好不在服务端备份中。
- 工具参数和结果可能含敏感内容，调用记录保存在聊天文件并进入完整备份；不要公开个人备份。
- Windows/Node 24 的自动测试和干净目录安装检查不等于全新电脑、所有操作系统或 DSH 全部插件的验收。
